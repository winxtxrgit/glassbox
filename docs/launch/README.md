# Launch content (drafts)

Ready-to-post drafts for taking glassbox public (Week 3 of `../ROADMAP-30DAY.md`).
**Nothing here is published** — each file is a draft for you to review, tweak in
your own voice, and post from your own account.

| File | Where | Notes |
|---|---|---|
| `blog-post.md` | dev.to / personal blog | Has front-matter; set `published: true` and a `canonical_url`. The canonical long-form piece. |
| `show-hn.md` | Hacker News (Show HN) | Title + URL + the first comment to post immediately after. |
| `reddit-localllama.md` | r/LocalLLaMA (+ r/MachineLearning `[P]`) | Leads with the finding; honest caveats up front. |
| `x-thread.md` | X / Twitter | 7-tweet thread. |
| `good-first-issues.md` | GitHub issues | 7 drafted issues to seed contributions; `gh issue create` snippet included. |

Suggested order: post the **blog** first so the others can link to a canonical
writeup, then r/LocalLLaMA, then Show HN (weekday morning US time lands best),
then the X thread. File the good-first-issues before any of the above so arrivals
find something to pick up.

All numbers in these drafts come from `../../FINDINGS.md` and
`../../benchmarks/RESULTS.md` — if you re-run with a bigger corpus, update those
first and the drafts second.
